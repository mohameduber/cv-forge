# CVForge — بناء سير ذاتية احترافية (عربي + إنجليزي)

أداة ويب مجانية لبناء سير ذاتية وتحميلها كـ PDF. تدعم العربية بشكل صحيح (RTL) و3 قوالب مختلفة.

## المميزات

- بني سيرتك في دقائق — بدون تسجيل حساب
- عربي + إنجليزي بضغطة زر
- 3 قوالب احترافية (Classic, Modern, Minimal)
- حفظ تلقائي في المتصفح
- تحميل PDF بنقرة واحدة (طباعة حقيقية — جودة نص عالية)
- صورة شخصية (بتتصغر تلقائياً)
- نظام ترخيص Lemon Squeezy جاهز (ادفع مرة واحدة وشيل العلامة المائية للأبد)

## التشغيل المحلي

1. افتح المجلد `cv-builder` في أي متصفح (دوبل كليك على `index.html`)
2. شغل بناء السيرة — كل حاجة بتتحفظ في المتصفح تلقائياً
3. للحذف وإعادة البداية: اضغط "New CV"

## النشر على الإنترنت (مجاني)

### الخيار 1: Netlify Drop (الأسهل)
1. ادخل [app.netlify.com/drop](https://app.netlify.com/drop)
2. اسحب مجلد `cv-builder` بالكامل وأفلته
3. هيطلعلك رابط زي `random-name.netlify.app` — ده موقعك
4. في Settings > Change site name — غيّر الاسم زي ما تحب

### الخيار 2: Vercel
1. ارفع المجلد على GitHub
2. اربط الـ repo بـ [vercel.com](https://vercel.com)
3. Vercel هينشره تلقائياً

### الخيار 3: GitHub Pages
1. ارفع على GitHub
2. في Settings > Pages > Source:/Branch: main, folder: /cv-builder
3. هيشتغل على `username.github.io/repo-name`

## ربط الدفع (Lemon Squeezy)

### الخطوة 1: حساب + متجر
1. اعمل حساب مجاني على [lemonsqueezy.com](https://www.lemonsqueezy.com)
2. خلّص التحقق من البريد الإلكتروني
3. اعمل Store جديد (اسم المتج: مثلاً "CVForge")

### الخطوة 2: المنتج
1. من Dashboard → Products → New Product
2. الاسم: "CVForge Pro License"
3. النوع: One-time purchase
4. السعر: $4.90 (أو أي سعر تحبه)
5. فعّل "License Keys" — ده بيدي كل عميل مفتاح فريد
6. حد الأجهزة: 3 (بيسمح للمستخدم يستخدم على 3 أجهزة)
7. احفظ المنتج

### الخطوة 3: ربط الموقع
1. من صفحة المنتج → "Share" → انسخ الـ Checkout URL
2. افتح ملف `config.js` في Notepad
3. الصق الرابط في `checkoutUrl`:

```js
window.CVFORGE_CONFIG = {
  checkoutUrl: "https://YOURSTORE.lemonsqueezy.com/checkout/buy/XXXXX",
  price: "$4.90"
};
```

4. ارفع المجلد المعدّل على Netlify تاني (اسحب وأفلت — بيعوض الموقع القديم)

### الخطوة 4: استلام الفلوس
- Lemon Squeezy بيبعت الفلوس على PayPal أو Payoneer
- PayPal شغال في مصر (بيتحول لبنك محلي)
- Payoneer شغال في مصر كمان
- الدفعات: أسبوعية أو شهرية حسب الإعدادات

## خطة الترافيك (إزاي تجيب ناس)

### SEO (مجاني — بياخد وقت بس أقوى حاجة)
1. اعمل صفحة لكل دولة/لغة: "resume builder uae", "سيرة ذاتية بالعربي", "CV builder saudi arabia"
2. استخدم Google Search Console (مجاني) — اسجّل الموقع وابعت sitemap
3. اكتب مقالات قصيرة: "أزاي تكتب سيرة ذاتية محترفة", "Best resume format 2026"
4. كل صفحة مقالة = زبون محتمل

### وسائل التواصل (مجاني)
1. اعمل فيديوهات قصيرة (TikTok / YouTube Shorts / Instagram Reels) — اعرض الـCV Builder وانت بتبني سيرة في 30 ثانية
2. نشر على Reddit: r/resumes, r/jobs, r/egypt (بصيغة مفيدة، مش إعلان)
3. نشر على Product Hunt (يوم الإطلاق هجيب traffic كبير)
4. نشر على Facebook groups: مجتمعات البحث عن شغل في مصر والخليج

### إعلانات مدفوعة (لو عندك ميزانية صغيرة)
1. Facebook Ads — استهدف: باحثين عن عمل، خريجين جدد، دول عربية
2. бюджет: $5-10/يوم = كفاية في البداية
3. الـ ROI: لو 100 زبون شهرياً × $4.9 = $490 — مقابل $150 إعلانات = أرباح $340

## ملفات المشروع

```
cv-builder/
├── index.html      ← الصفحة الرئيسية
├── config.js       ← إعدادات الدفع (Lemon Squeezy)
├── styles.css      ← التصميم
├── app.js          ← كل المنطق (محرر + قوالب + طباعة + ترخيص)
└── README.md       ← دليلك ده
```

## لو عايز تعدل أي حاجة

- **القوالب:** ابحث عن `.tpl-classic`, `.tpl-modern`, `.tpl-minimal` في `app.js`
- **الألوان:** غير `--accent` في `DEFAULT_STATE` في `app.js`
- **الترجمة:** ابحث عن `const TEXT` في أعلى `app.js` — فيه كل النصوص بالإنجليزي والعربي
- **السعر:** غيّر `price` في `config.js`
- **الـ CSS:** كل حاجة في `styles.css` + جزء في `CV_CSS` داخل `app.js`

## ملاحظات تقنية

- **زيرو سيرفر** — كله static، مش محتاج Node.js ولا أي حاجة
- **زيرو بناء** — افتح المجلد وشغّل
- **البيانات** — بتتحفظ في localStorage (في المتصفح بس)
- **الطباعة** — بيستخدم print() بتاع المتصفح — جودة PDF نص حقيقي مش صورة
- **RTL** — العربية شغالة صح: النص من اليمين لليسار، التخطيط معكوس
- **الصور** — بتتصغر تلقائياً وتحتفظ في localStorage (حد أقصى ~300KB)
